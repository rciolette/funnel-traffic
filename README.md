# Funnel Traffic

Mapa de funil ligado a eventos reais. Cada etapa é uma regra sobre eventos; cada linha, uma taxa de conversão entre pessoas únicas. Conectores por webhook + mapper JSON, n8n como conector universal, pixel próprio.

Produto da RC Digitais, white label e multi-cliente. Comece por `CLAUDE.md` e `CONTEXTO_ATUAL.md`.
